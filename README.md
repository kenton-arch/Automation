# Automation

Tools for capturing and automating repeated work.

## Task Capture

`task-capture/index.html` is a one-page recorder. A person clicks Start, does a task while talking through it, and clicks Stop. It saves one zip file with screenshots and a timeline of what they said. Nothing is uploaded anywhere; the file stays on their computer until they send it.

- Works in Chrome or Edge on a computer.
- Needs to be opened from a web address (not a downloaded file) so the microphone permission is remembered.
